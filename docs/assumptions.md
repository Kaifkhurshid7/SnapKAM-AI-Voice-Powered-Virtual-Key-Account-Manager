# Assumptions

Assumptions made beyond the provided seller data. Add to this list as the build progresses.

- Seller data is static mock data from the assignment brief ([data/seller-data.json](../data/seller-data.json)).
- Derived figures (for example, sales change of about -32.5% and orders change of about -32.5%) are computed from that data.
- Average selling price is unchanged, so the sales drop is attributed to volume rather than pricing.
